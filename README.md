# 🚀 Futuristic M3U8 / M3U IPTV Player — Chrome Extension

A modern, futuristic Chrome Extension that allows you to play **M3U8 streams** and **M3U playlists** directly inside the browser with a clean glass UI and built-in video player powered by **HLS.js**.

No external player. No complicated setup. Just open and play.

---

## ✨ Features

* ▶️ Play any **.m3u8** stream URL
* 📂 Upload and parse **.m3u** playlist files
* 📺 Clickable channel list from playlist
* 🧊 Futuristic glass UI design
* ⛶ Fullscreen video mode
* 🧠 Powered by HLS.js for smooth playback
* 🌐 Works with most IPTV / live stream sources

## 🔧 Installation (Developer Mode)

1. Download or clone this repository
2. Open Chrome and go to: `chrome://extensions`
3. Enable **Developer mode**
4. Click **Load unpacked**
5. Select the extension folder

Done ✅

---

## 🖥️ How to Use

### Play M3U8 URL

1. Click the extension icon
2. Paste your `.m3u8` link
3. Click **Play Stream**

### Load M3U Playlist

1. Click **Choose File**
2. Select your `.m3u` playlist
3. Click any channel to start playing
